# Partner logos for integration cards

Logos that `scripts/generate-integration-card.mjs` places next to the Everruns,
Yolop, Bashkit or Mira mark on a changelog integration card. One SVG per
partner, named by the slug passed to `--partner`.

The current files come from [Simple Icons](https://simpleicons.org) 13.21.0
(CC0-1.0), recolored to each brand's color from the Simple Icons data. A partner
without a file renders as its name in a wordmark tile, so a card never waits on
a logo. Add a logo only from the partner's own brand kit or Simple Icons, and
follow the partner's brand guidelines.
