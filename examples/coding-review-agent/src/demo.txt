ANSWER

**Reproduced defect:** `assertion left == right failed: two refunds must not exceed the original payment — left: 2000, right: 1000`. `refund()` caps each request individually against `order_total_cents` but has no memory of prior refunds, so two $10 refund requests on a $10 order each return $1000 (cents), yielding $2000 total — violating the contract's cumulative cap.

**Impact:** Double (or repeated) refunds can be issued for the same order, allowing customers/attackers to drain more money than was paid — a financial/business-logic bug.

**Minimal fix:** Track cumulative refunds already issued per order (e.g., pass/store `already_refunded_cents` and compute `requested.min(order_total_cents.saturating_sub(already_refunded_cents))`), rather than only bounding by the original total.
