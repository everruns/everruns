# everruns-serve-macros

Attribute macros for [`everruns-serve`](https://crates.io/crates/everruns-serve):
`#[agent]`, `#[tool]`, `#[channel]`, `#[schedule]`, `#[connection]` and `#[eval]`.

> **Experimental.** No compatibility promise. Applications depend on
> `everruns-serve`, which re-exports these macros; do not depend on this crate
> directly.
