# Observability

Everruns provides observability integrations to help you monitor, debug, and evaluate your agentic workflows.

## Integrations

### Braintrust

<img src="/images/observability/braintrust-logo.png" alt="Braintrust" width="64" />

LLM observability, evaluation, and trace visualization.

[Get Started with Braintrust](/observability/braintrust/)

### OpenTelemetry

Standard distributed tracing via OTLP export to Jaeger, Grafana Tempo, or any OTLP-compatible backend.

See [Environment Variables](/sre/environment-variables/#opentelemetry-configuration) for configuration.
