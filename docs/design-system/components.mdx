## Buttons

`components/ui/button.tsx`. 32px high, 14px medium label, 16px icon. Hover is the same fill at
90%. Focus is a 3px ring in `ring / 0.5` with the border switching to `ring`.

The tier matters more than the look:

| Tier | Variant | Used for |
|---|---|---|
| Create | `accent`: gold fill, navy label | The one "make a new thing" action on a page: New agent, New harness, Add model, Test in Playground. |
| Commit | `default`: navy fill | Saving an edit: Save changes. Never on a read-only page. |
| Secondary | `outline` | Everything else in an action cluster: Edit, Copy, Export, Discard, Analyze. |
| Quiet | `ghost` | Card footers, toolbars, Cancel in dialogs. |
| Destructive | ghost icon in `destructive` | Row-level delete. Never a filled red button in a list. A filled `destructive` button is for the confirm step of a destructive dialog. |

- One create or one commit action per page, never both. The create button sits last (far
  right) in its cluster; Save changes sits first, with Discard to its right.
- An action cluster holds at most six buttons. More go into the `⋯` menu, which also holds
  History, Manager notes, Archive, and Delete ([entity actions menu](https://github.com/everruns/everruns/blob/main/knowledge/ui/entity-actions-menu.md)).
- Labels are verbs in sentence case: "New session", not "New Session" or "Create".

## Badges, status, and tags

Three different things that look alike. Do not interchange them.

- **Badge** (`components/ui/badge.tsx`): an informational label. 11px medium, sentence case,
  sharp corners. `success` for positives such as Enabled, `secondary` for neutral facts
  (Built-in, Idle), `accent` for a transient mode (Editing, Draft), `outline` for plain
  labels, `destructive` only for failure. The id chip is mono with a navy 6% tint.
- **Status** (`components/ui/entity-status.tsx`): lifecycle on overview surfaces such as cards
  and rows. A 6px dot and a 12px muted label. Color is a second cue; the word carries the
  meaning. The masthead of a detail page may use a filled badge for the same state.
- **Tag** (`components/ui/tag-input.tsx` for editing): a quiet `muted / 0.6` fill, 12px, no
  border. Three show on a card, then `+N`.

## Inputs and fields

`components/ui/input.tsx`, `textarea.tsx`, `select.tsx`, `search-input.tsx`. 32px high, card
surface, `input` border, the gold ring on focus. Labels are 12px medium muted, above the

## Tabs and view toggle

`SectionTabs` in `components/ui/tabs.tsx`. 13px, optional icon and muted count; the selected
tab is 600 weight with a 2px navy underline. Tabs filter a list by status, or switch the
sections of a detail page. The grid and list toggle sits at the end of a list's control strip.

Anatomy, top to bottom:

1. A plain 20px domain glyph (no tile; only the page masthead uses a tile), an 18px semibold
   linked title, and the lifecycle status at the top right.
2. The description at `foreground / 0.75`, clamped to two lines.
3. Detail rows: `icon · label · value`, such as the harness. Agent channels sit here, above
   tags; harness cards have no channels.
4. Capabilities as icon and name, four, then `+N`. Tags, three, then `+N`. Overflow controls
   are keyboard accessible and reveal the full set.
5. A footer strip with usage on the left and ghost actions on the right.

Rules: only the title and explicit links navigate, the card itself is inert. Never fix a card's
height; let the body grow. No shadow; hover darkens the border. Slugs, ids, and creation dates
belong on the detail page.

## Navigation

- Groups, in order: Chat (no label), Building, Operational, Library, Quality, then Settings,
  System (collapsed), and Dev in development builds. The navigation model in
  `lib/navigation.ts` owns the item list; breadcrumbs take their group name from it.
- Group labels are 12px medium muted sentence case. Groups are separated by 12px of space,
  never by rules.
- An item is a 13px label with its 16px Facet glyph. Selected: a 2px navy left marker, a
  `primary / 0.05` tint, 600 weight. Hover: a border-colored marker and a light fill.
- Experimental items carry the Lucide flask after the label.

## Notices, banners, and empty states

<DsExample flush>

    <div class="ds-empty">

    </div>
  </div>

- **Banner**: one full-width strip above the app shell, gold 10% tint, a glyph, a bold lead and
  a muted continuation, one link, and a dismiss button. One at a time, never stacked.
- **Notice** (`components/ui/notice.tsx`): an inline bordered message inside a page.
- **Empty state**: teach what the thing is and offer the first action. Zero counters are
  hidden rather than shown as "0".
- Errors shown to ordinary users are short and generic. Full error detail belongs to the
  developer surfaces, such as the session trace.
