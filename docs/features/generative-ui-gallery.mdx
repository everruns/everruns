Browse **69 components in 39 examples**, from simple text and cards to forms,
charts, tables and overlays. These are live components using the same renderer
as console chat and Work Chat. Try the inputs, submit forms, switch tabs, hover
charts, and open overlays. Use **Reset** to start an example again.

Actions display their message and form values below the example. They stay in
your browser; no account, agent run, or conversation is created. Examples follow
the docs' light or dark theme. External maps and media load when you select
**Load interactive example** and depend on the external service being available.

Expand **A2UI example** to copy the complete surface operation. See
[Generative UI in chat](/features/generative-ui/) for setup, message actions,
and rendering limits.
