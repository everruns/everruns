Browse **69 components in 39 examples**, from simple text and cards to forms,
charts, tables and overlays. The 32 screenshot previews show authored examples in
the same renderer used by console chat and Work Chat. Previews follow the docs'
light or dark theme; select an image to enlarge it.

**The previews are screenshots, not live controls.** Expand **A2UI example**
to see each complete surface operation. To use interactive components, enable
the **A2UI** capability on an Agent and try them in an editable chat.
See [Generative UI in chat](/features/generative-ui/) for setup, message
actions and rendering limits. Seven examples that depend on external maps or
media include source only. Screenshots cannot demonstrate playback, hover,
scrolling or opening an overlay.
