New application code should use the [Everruns Framework](/framework/) through
the application-facing `everruns` crate. It provides agents, open
model/provider configuration, typed tools, sessions, events, cancellation,
files, MCP, and context inspection without requiring applications to assemble a
low-level execution host.

`everruns-runtime` remains published and supported throughout 0.17.x. Existing
applications do not need to migrate immediately, and advanced embedders may
continue using it for host backends, platform definitions, phase adapters, and
in-memory execution topology.

See [Runtime compatibility](/framework/runtime-compatibility/) for the
application migration map and [Custom backends](/framework/custom-backends/)
for the low-level embedding boundary.
