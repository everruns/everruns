## What you need

<Steps>
1. Open a Python 3.10+ notebook kernel
2. Set `EVERRUNS_API_KEY` before running against `https://app.everruns.com/api`
3. Override `EVERRUNS_API_URL` only when you want to point the notebook at a local or self-hosted Everruns instance
</Steps>

## Why this example uses `harness_name="generic"`

The Generic harness is the default starting point for most Everruns sessions. It gives the session a sensible base environment without forcing notebook users to wire up custom harness data first.

If you want to understand the rest of the SDK surface after this first pass, continue with [Building Agents Using the Everruns SDK](/tutorials/building-agents-using-sdk/).
