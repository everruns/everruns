Everruns is a **durable agentic harness engine** built on Rust. It provides APIs for managing agents, sessions, and long-running tasks with real-time event streaming via SSE.

## Get Started

<Steps>
1. Read the [Introduction](/getting-started/introduction/) to understand core concepts
2. Deploy with [Docker Compose](/getting-started/docker-compose/) in minutes
3. Create your first agent via the [API](/api/) or [Management UI](/features/ui/)
</Steps>
