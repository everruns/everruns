Everruns is a **durable agentic harness engine** built on Rust. It provides APIs for managing agents, sessions, and long-running tasks, with real-time SSE event streaming and PostgreSQL-backed durability.

Use it in one of three ways: embed the [Framework](/framework/) in a Rust
application, run the Platform yourself, or use [Everruns Cloud](/getting-started/cloud/)
and let Everruns operate it. [Start here](/getting-started/introduction/) compares
the three.
