## Build your first Slack Agent

Start with a job: answering team questions, researching a topic, or preparing an incident handoff.

<div className="slack-steps">
  <article>
    <div className="slack-step-number">01 / DEFINE</div>
    <h3>Create the Agent</h3>
    <p>
      Set its name, avatar, instructions, and model. Add capabilities or MCP
      tools for its job.
    </p>
  </article>
  <article>
    <div className="slack-step-number">02 / CONNECT</div>
    <h3>Add Slack</h3>
    <p>
      In Integrations, add a Slack channel. Choose a session per thread,
      channel, or user.
    </p>
  </article>
  <article>
    <div className="slack-step-number">03 / PUBLISH</div>
    <h3>Invite your team</h3>
    <p>
      Publish the channel, select a connected workspace, choose Add to Slack,
      and approve the installation. Invite the bot and send a message.
    </p>
  </article>
</div>

<p className="slack-note">

  administrator approval. Self-hosted deployments need public HTTPS.{" "}

</p>

## Make it a Slack Agent

Enable the Agent surface on your Slack channel to give it a dedicated pane alongside channel conversations. Replies stream in the pane; channel threads receive completed messages.

<p className="slack-note">
  Existing Slack apps need an updated manifest and reinstall to grant the Agent
  surface permissions.
</p>

[Configure Slack’s agent pane →](/capabilities/slack/#agent-surface)
