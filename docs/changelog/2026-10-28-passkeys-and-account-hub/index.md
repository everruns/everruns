Everruns Cloud now has a shared account hub with optional passkey protection.
Open **Settings > Profile > Manage your Everruns ID**, then choose **Security >
Add a passkey**. Follow your browser's native prompt and save the recovery codes.

The hub also lists sign-in devices and personal connections across your
organizations, including AI clients, MCP servers, services, credentials, and
API tokens. Review permissions and recorded usage, then revoke access you no
longer need. New ID sessions show a masked IP address and approximate sign-in
location. Ending an ID session leaves separate app sessions valid until expiry.

See the [Cloud quickstart](/getting-started/cloud/) for enrollment and account
management.
