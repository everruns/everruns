The Everruns ID login page now links to a dedicated sign-up page, so creating
an [Everruns Cloud](https://app.everruns.com) account is an explicit step.
Entering an unused email on the login form still creates an account.

Verification and password-reset emails now carry the Everruns logo, an action
button, a visible fallback link and an expiry note, with a complete plain-text
version. A login started directly at Everruns ID, rather than from the app, now
finishes on app.everruns.com instead of the ID landing page.

See [Everruns Cloud quickstart](/getting-started/cloud/).
