New organizations on [Everruns Cloud](https://app.everruns.com) come with a
built-in model provider, so an agent can run before you have any provider API
keys. Its models included GPT 5.6 Sol, Claude Sonnet 4.6, Muse Spark 1.3 and
Muse Spark 1.3 Contributor. A user's first organization receives $5 of starter
credit, once per account and only with a verified email.

**Settings** > **Billing** shows available credit, the starter and purchased
split, and what running work holds. Owners and admins buy more credit there;
every member can see the balance. At zero balance the built-in provider refuses
new calls, while models on your own provider keys keep working.

See [Everruns Cloud quickstart](/getting-started/cloud/).
