The console sidebar has fewer, clearer groups. **Overview** sits right under
Main chat and Side chats, with no group header, because it is the
organization's home page. **Build** holds just Agents and Playground. **Activity**
holds what ran: Sessions, Rooms and Monitoring. **Blocks** holds everything
agents are made from and run on, starting with what agents use by name
(Harnesses, Capabilities, Skills, Plugins, Knowledge, Memory, Extractions,
Virtual Users) and ending with the pages that hold provider accounts (Models,
Web search, Sandboxes). Quality and Settings are unchanged.

Before, Extractions sat above Overview at the top of Building, and Models and
Web search shared a Library group with Capabilities and Knowledge. Breadcrumbs,
Cmd-K search and the Chat first navigation rail follow the same groups. Every
page keeps its URL. See [UI](/features/ui/) for the full list.
