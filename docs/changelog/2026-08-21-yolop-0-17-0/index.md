Yolop 0.17.0 ships these changes:

- [Yolop config and data directories can be relocated](/changelog/2026-08-18-yolop-relocatable-config-dirs/)
- [Yolop model switching uses a curated list you manage](/changelog/2026-08-20-yolop-curated-model-list/)
- [Yolop installs compiled extensions with prebuilt binaries](/changelog/2026-08-20-yolop-extension-prebuilt-binaries/)

Before upgrading, read the breaking changes: [Yolop model switching uses a curated list you manage](/changelog/2026-08-20-yolop-curated-model-list/).
