# Archived Python prototype

These files were the previous ad-hoc gateway, retrieval script, verifier, runtime probe, and result evidence. They are retained to inspect the earlier prototype and its evidence. The canonical study and protocol fixture now live in the parent `mcp-scale` crate as a Mira Rust study using the current Framework working tree. Results in this directory do not measure that Rust study.

The original Rust probe manifests are preserved as `runtime/Cargo.toml.snapshot` and `runtime/Cargo.lock.snapshot`. They record the original dependency resolution. The active build and security checks belong to the canonical [Rust/Mira study](../../README.md).
