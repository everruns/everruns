# Agent Identities

## Goal

Verify identities can be created, assigned to sessions/apps, and preserved in unattended flows.

## Cases

1. Create an identity with locale/timezone defaults from `/agent-identities/new`.
2. Create a new session and assign the identity in the creation dialog.
3. Create a new app and assign the identity in the creation form.
4. Edit an existing app and swap the identity.
5. Archive the identity and confirm it remains visible historically but is no longer assignable for new work.
