## Findings considered and rejected

Recorded so they are not re-audited next run.

**Security (the UI is well-defended; most security findings were false positives):**
- `window.open(url, "_blank", "noopener,noreferrer")` flagged as ignoring
  `noopener`: false — `noopener`/`noreferrer` are valid `windowFeatures` tokens.
- Raw-HTML XSS via the markdown renderer: false — `streamdown` does not render
  raw HTML, and mermaid runs with `securityLevel: strict`.
- Frontend should enforce cookie `HttpOnly`/`Secure`/`SameSite`: not feasible —
  HttpOnly cookies are unreadable from JS; this is a backend concern.
- A2UI form CSRF / client-side authz / field-name sanitization: speculative
  ("if the LLM is compromised"); dispatch is constrained to same-session
  `message` + allowlisted `open_url`, the backend authorizes, and React escapes.
- Open-redirect in login `return_to`: already handled by `sanitizeReturnTo`
  (rejects non-`/`, `//`, `/\`).
- `MarkdownLink` `javascript:` href: low — `streamdown` sanitizes hrefs upstream;
  kept only as an optional defensive note, not worth a plan.

**Dependencies:**
- Next.js 16 / React 19 flagged as "bleeding-edge canary": false premise — both
  are stable releases as of 2026.
- "Three redundant UI primitive libraries": overstated — `@base-ui/react` is the
  standard; `radix-ui` is one file (→ plan 003); `@openuidev/react-ui` is a
  separate feature (OpenUI block rendering), not a redundant primitive.

**Performance / correctness:**
- `use-global-search` "9× linear scans per keystroke": overstated — the
  if/else-if chain runs one `.find()` per prefixed query, O(m) once. Not worth it.
- `use-durable` non-null assertions (`getWorkflow(workflowId!)` with
  `enabled: !!workflowId`): by-design — idiomatic TanStack Query pattern.

### Direction (options for the maintainer, not problems)

- **E2E coverage is a single spec** (`e2e/message-components.spec.ts`); no
  end-to-end journey covers login → session → message → response. A spike plan to
  stand up one critical-journey E2E would be high-value before the suite grows.
- **Feature-flag hygiene**: `experimental-badge` + flags (`app_budgets`,
  experimental Chat/Evals nav) are live with no documented rollout state; worth a
  reconcile pass to retire fully-rolled-out flags.
