# Agent Identities

Agent identities are replaced by the service usage of [Virtual Users](virtual-users.md).
Existing identifiers and service grants retain their identity. Agent behavior and personas
remain separate from the runtime account. See that contract for ownership, private connection
selection, console self bindings, migration, and runtime authorization.
