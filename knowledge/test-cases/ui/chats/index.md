# Chats (UI)

* [TC001: Chats - Landing Route and New Thread](TC001_chats_landing_and_new_thread.md) - Verify that Chats is the app's landing route, that the empty state starts a thread rather than spinning, and that a new thread opens on the thread surface bound to the agent that was picked.
* [TC002: Global Chat - Create Agent via Chat](TC002_create_agent_via_chat.md) - Verify that the global chat agent can create a new agent when asked, using the `manage_agents` platform management tool.
* [TC003: Global Chat - Create 10 Random Agents](TC003_create_10_random_agents.md) - Verify that the global chat agent can create 10 distinct agents in a single conversation when asked.
* [TC004: Global Chat - Run Agent via Chat](TC004_run_agent_via_chat.md) - Verify that the global chat agent can run a previously created agent by creating a session, sending a message, waiting for completion, and relaying results.
* [TC005: Global Chat - Run All 10 Agents](TC005_run_all_10_agents.md) - Verify that the global chat agent can run all 10 previously created agents sequentially, each with a relevant task, and relay all results.
* [TC006: Global Chat - Verify Agents in Agents Page](TC006_verify_agents_in_agents_page.md) - After creating agents via global chat, verify they appear correctly in the Agents listing page with proper display names, slugs, status, and details.
* [TC007: Global Chat - Verify Sessions Created by Agent Runs](TC007_verify_sessions_created.md) - After running agents via global chat, verify that sessions were created and are visible in the Sessions page with correct agent associations and idle status.
* [TC008: Global Chat - Multi-turn Agent Management](TC008_chat_multi_turn_agent_management.md) - Verify that global chat supports multi-turn conversation for agent management: create an agent, run it, check results, then update the agent — all in one conversation.
* [TC009: Global Chat - Error Handling for Agent Operations](TC009_chat_error_handling.md) - Verify that global chat handles error cases gracefully: running a nonexistent agent, creating a duplicate agent name, and interacting with invalid references.
* [TC010: Chats - Available Without Configuration](TC010_chats_available_without_configuration.md) - Verify that every Chats route and the sidebar are available to a fresh organization without feature configuration, including the app's landing redirect.
* [TC011: Chats - Sidebar Thread List](TC011_sidebar_thread_list.md) - Verify that the sidebar lists the most recently active threads under Chats, capped at five, and that the list does not re-order under the cursor while the pointer is inside it.
* [TC012: Chats - Thread Switching and Inline Run Cards](TC012_thread_switching_and_run_cards.md) - Verify that switching threads does not leak transcript state between them, and that a reply which started a run renders an inline run card in the turn that started it.
* [TC013: Chats - Pin Chat](TC013_pin_chat.md) - Verify that a chat can be pinned or unpinned from both the Chats list and the open thread, and that pinned chats stay ahead of more recently active unpinned chats.
* [TC014: Chats - Harness-Bound Thread](TC014_harness_bound_chat.md) - Verify that a user can start a chat directly from an active Harness without creating or selecting an Agent, and that the resulting thread remains bound to that Harness.
* [TC014: Chats - Model Resolution Guard](TC014_model_resolution_guard.md) - Verify that Chat does not admit a turn without a resolvable model and can send a later message once an explicit model becomes available.
* [TC015: Chats - Archive Chat](TC015_archive_chat.md) - Verify that a chat can be archived and restored from both the Chats list and the open thread, that archived chats leave the default list and the sidebar, and that the **Show archived** filter brings them back without...
