# Personal access tokens (UI)

* [TC001: Personal Access Token User-Scoped Access](TC001_personal_access_token_user_scoped.md) - Verify that a personal access token created through the UI grants access to all organizations the user belongs to.
* [TC002: Personal Access Token - Read-only and Revocation](TC002_read_only_and_revocation.md) - Verify that read-only tokens can read authorized organization data, reject writes and token management, and stop authenticating after revocation.
* [TC003: Personal Access Token - Expiration Boundaries](TC003_expiration_validation.md) - Verify expiration presets, custom-day validation, explicit non-expiring choice, and dialog reset without silently broadening token access.
