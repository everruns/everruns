# Org creation (API)

* [TC001: Created Organization Visible in List](TC001_created_org_visible_in_list.md) - Verifies that a newly created organization immediately appears in the user's organization list without requiring re-login or page refresh.

* [TC003: Get Created Organization by ID](TC003_get_created_org_by_id.md) - Verifies that a newly created organization can be fetched by its ID immediately after creation.
